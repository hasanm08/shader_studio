# Shaders

Each `.frag` file is a Flutter runtime effect. They include `flutter/runtime_effect.glsl`, write `out vec4 fragColor`, and list uniforms in the order documented at the top of the file.

The files are registered under `flutter: shaders` for `FragmentProgram.fromAsset`. Flutter rejects the same path under `flutter: assets`. The code panel reads `ShaderSources`, regenerated by `dart run tool/mirror_shader_sources.dart`. The contract test fails if that mirror drifts from these files.

Noise helpers are copied into the shaders that need them. Flutter's include path is the SDK shader library, so a private shared `.glsl` is not something this project depends on. Duplication keeps each sample readable on its own.

`uTime` is seconds wrapped by Dart into `[0, 600)`. See `ShaderController.timeWrapSeconds`.

No shader in this folder samples a texture. Do not add a sampler unless the Dart writer and the uniform contract are updated together.
